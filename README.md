# cr8rproject.github.io

Compiled build of the CR8R app. **Build artefact only, do not edit by hand.**

The source lives in the private repo `cr8rproject/cr8r-v2`. Every file here is
regenerated by `scripts/deploy-pages.sh` from that repo (`npx vite build`)
and force replaced on each deploy, except the previous build's hashed files in
`assets/`, which stay one more deploy so a tab still open on it can load its
screens (`.assets-manifest` lists the files of the current build).

Live at https://cr8rproject.github.io
